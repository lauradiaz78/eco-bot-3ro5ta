💡 ¿Qué es el Proyecto Eco-Bot?

👵 Explicado en sencillo para la familia:

El grupo de trabajo tomó una barredora manual de las que se usan en las casas y le agregó motores, baterías y un "cerebro electrónico" (Arduino). Ahora la barredora caminadora puede moverse sola y usar "orejitas invisibles" (sensores ultrasónicos) para esquivar muebles y paredes sin chocar.

⚙️ Mecánica Original

La barredora funciona mediante rodillos y cepillos que giran por fricción cuando las ruedas tocan el suelo, recogiendo residuos hacia un compartimento interno.

🤖 Automatización Robótica

Al motorizar la tracción trasera y añadir sensores en los 4 lados, el prototipo del grupo recorre los espacios y toma decisiones de giro automáticamente.

📐 Plano de Montaje y Distribución

📍 ¿Cómo está distribuido por dentro?

Las baterías van en la zona trasera para dar peso a las ruedas. En el centro van las placas electrónicas protegidas y en los 4 extremos (frente, izquierda, derecha y atrás) se colocan las "orejas" (sensores) para cuidar al robot en todas direcciones.

📸 Avances del Grupo en el Taller

Trabajo del grupo de 3° 5° clase a clase durante las 8 semanas de taller:

Fase 1: Análisis de la estructura y prueba de componentes electrónicos en mesa.
Fase 2: Perforación, soporte de motores traseros y montaje de ruedas al 50%.
Fase 3: Soldadura de cables, orden en la protoboard y colocación de sensores.
Fase 4: Pruebas de funcionamiento en pista esquivando obstáculos.

💻 El "Cerebro" de Eco-Bot (Programación)

🧠 ¿Cómo piensa el robot?

El programa hace que el robot revise su sensor del frente constantemente. Si no hay nada a menos de 25 cm, avanza. Si encuentra una pared, se frena, mira a la izquierda y derecha, elige el camino libre y vuelve a avanzar.

Ver código fuente completo para Arduino Nano (C++) 
// Pines de control de motores
const int IN1 = 5;  const int IN2 = 6;
const int IN3 = 9;  const int IN4 = 10;

// Pines Sensores Ultrasónicos
const int trigFrente = 2;    const int echoFrente = 3;
const int trigDerecha = 4;   const int echoDerecha = 7;
const int trigIzquierda = 8; const int echoIzquierda = 11;
const int trigAtras = A0;    const int echoAtras = A1;

const int distSeguridad = 25; // cm

void setup() {
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT);
  pinMode(trigFrente, OUTPUT); pinMode(echoFrente, INPUT);
}

void loop() {
  int distFrente = medirDistancia(trigFrente, echoFrente);
  if (distFrente > distSeguridad) {
    avanzar();
  } else {
    detener();
    // Revisa esquinas y decide hacia dónde girar...
  }
}
